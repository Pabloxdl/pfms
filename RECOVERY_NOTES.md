# PFMS source recovery

This directory was recovered from the published `PFMS.dll` version 1.3.0.0 found on this PC on 2026-09-10.

## Contents

- `Pfm*`, `Pfm.Core.*`, and `Pfm.Services.*` contain decompiled C# for the application logic, UI, macros, input, vision, fishing, and configuration features.
- `original-runtime` preserves the original published runtime, including `PFMS.dll` and all 216 dependency files. It was copied from the temporary .NET extraction folder so Windows cleanup cannot remove the only binary copy.
- `PFMS.csproj` was generated by ILSpy and points to `original-runtime` for its dependency references.

## Recovery limits

The original source project was not found on the computer, GitHub, or in the published runtime. In particular, no original `.csproj`, `.axaml`, source-control history, or PDB symbols were available.

The recovered project now builds successfully with the installed .NET 10 SDK and starts normally. The source still contains decompiler-generated Avalonia UI code, so it should be cleaned up gradually before significant feature work.

Build command:

```powershell
dotnet build PFMS.csproj
```

The original executable remains available at `original-runtime/PFMS.dll`. Do not delete `original-runtime` until the recovered project has been rebuilt and tested.
